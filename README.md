# Viva Studio — সাত কোর্সের ইংরেজি ভাইভা প্রস্তুতি

Comprehensive web portal and interactive self-testing platform for 4th Year English Viva Voce (Batch 51, Jahangirnagar University).

## Courses Included
- **E403**: Critical and Cultural Theory
- **E404**: Sociolinguistics
- **E405**: Semantics and Pragmatics
- **E410**: Phonetics and Phonology
- **E411**: Morphology and Syntax
- **E412**: Psycholinguistics
- **E413**: Research Methods in Applied Linguistics and ELT

## Features
- **189 In-depth Topics**: Core idea, Viva-style spoken answer, Examples, In-depth analysis, and Common confusion warnings.
- **803 Questions**: Direct one-sentence answer, spoken viva response, key scoring points, detailed explanation, and cross-course links.
- **140 Essentials**: Targeted 2-day rapid preparation path (~20 key questions per course).
- **Interactive Practice Modes**: Course-specific, Mixed, Cross-course connections, and Timed Mock Viva.
- **Progress Tracking**: Local storage caching, Export/Import progress JSON, Spaced-repetition retry of missed items.
